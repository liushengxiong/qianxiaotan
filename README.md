# 黔小探 · 贵州亲子探索 Demo

「黔小探」是面向家长与孩子共同使用的贵州旅行探索原型。它以贵州九个地州市地图为入口，把一次旅行拆成景区概要、听一听、打卡任务、趣味挑战和电子相册，而不是景点列表、攻略门户或在线旅游交易平台。

本版依据 Notion 页面「黔行有知产品修改」于 2026-08-29 的内容更新。

## 可体验内容

- 每次打开首页都从 Onboarding 重新规划旅行，不读取、不上传、不持久化昵称、身份、进度、成绩或照片。
- 贵阳、安顺、遵义、六盘水、毕节、铜仁、黔东南、黔南、黔西南共收录 65 个景区入口，每个地区至少 7 个。
- 景区概要组合真实景区图片、介绍、轻量短片和小探知识库，删除旧版右侧行程清单。
- 90 条内容选题与完整文章同步到项目，按地区和景区名称匹配。点击知识卡片会在系统内直接阅读全文，不跳转外部页面。
- Notion 中的事实核验表、未采用信息、编辑状态等内部字段不会出现在产品界面。
- 打卡任务以三张任务卡呈现，需逐项完成后才能领取本页演示印章。
- “练知识”更新为“趣味挑战”，保留选择题、判断题、即时反馈和亲子回顾。
- 删除“做照片”；“留回忆”更新为“电子相册”。照片仅在浏览器内存中处理，可自动排版为可下载的视频。
- “我的手账”只保留贵州印章、趣味成绩和电子相册，删除旅行作品与探索足迹。
- 导航和功能图标使用 `@tabler/icons-react` 3.46.0，统一使用 1.8 线宽。
- 小探保持二维角色形象、文字/语音交互和当前景区上下文。

## 数据与能力边界

- 这是不保存任何用户数据的展示版本。页面刷新或重新打开后，Onboarding、打卡和答题状态都会重置。
- `/api/mobile/*` 在 Worker 中统一返回 `410`，前端不调用账户、数据库或照片上传接口。
- 电子相册通过 Canvas 与 MediaRecorder 在本机生成，不上传原图。
- 景区短片使用图片和文字动效呈现一分钟导览结构；正式上线前仍需替换为已获授权的视频文件。
- 产品内只呈现 Notion 已生成的亲子文章正文与趣味挑战，不展示内部编辑流程。
- 小探会结合当前景区文章与任务回答；涉及开放时间、安全与现场安排时，以景区公告为准。
- 打卡不获取定位、不验证到访。请遵守景区现场安全说明。

## 技术栈

- React 19 + TypeScript
- vinext / Vite / Cloudflare Worker
- Tailwind CSS 4 + 自定义响应式 CSS
- Tabler Icons React 3.46.0
- Canvas + MediaRecorder 本地电子相册

关键文件：

- `app/components/mobile-shell.tsx`：旅行导航与五段景区体验。
- `app/components/mobile-home.tsx` / `city-map.tsx`：九地州市地图和景区入口。
- `app/components/scenic-overview.tsx`：图文、短片和站内文章阅读。
- `app/components/mobile-journal.tsx`：本地照片选择和电子相册视频生成。
- `app/components/mobile-profile.tsx`：印章、趣味成绩和电子相册入口。
- `app/lib/catalog.ts`：65 个景区和探索数据。
- `app/lib/notion-content.ts`：Notion 内容库同步的 90 条选题。
- `app/lib/notion-articles.ts`：Notion 内容库同步的 90 篇完整文章与挑战题。
- `worker/index.ts`：站点入口，并关闭旧移动数据接口。

## 本地运行与验证

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
npm run typecheck
npm test
```

建议体验顺序：

1. 打开 `/`，完成称呼、身份和目的地选择。
2. 从地图选择安顺 → 黄果树瀑布。
3. 查看图文概要与一分钟短片，在小探知识库中站内阅读全文。
4. 听一听 → 完成三张打卡任务卡 → 趣味挑战。
5. 在电子相册中选择本地照片，生成并下载视频。
6. 刷新首页，确认重新进入 Onboarding；直接请求 `/api/mobile/state` 应返回 `410`。
